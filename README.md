One ingredient, one picture: honey. A macro honeycomb rendered procedurally
in pure Python (stdlib only) — organic irregular wax cells filled with
glossy amber honey, a thick honey drip falling into a droplet, and a pooled
honey gloss at the base. Warm directional light, shallow depth of field,
vignette, and fine grain.

Run `python3 main.py` to write a deterministic 1024x1024 PNG to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`).
