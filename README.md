A make.fun bounty entry: one picture of food that tastes of a single
ingredient — honey. A macro honeycomb, warm golden light, glossy honey
pooling and dripping, rendered procedurally in pure Python (stdlib only).

## Run

```
python3 main.py
```

Writes `entry.png` (1024x1024, deterministic) to `$MAKEFUN_OUTPUT_DIR`
or `/output`.
