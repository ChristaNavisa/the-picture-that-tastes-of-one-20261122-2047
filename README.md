One picture of food, judged on how delicious it looks. One ingredient:
**honey**.

`main.py` (Python 3.13, standard library only) renders a photorealistic-style
macro photograph of a honeycomb dripping with warm golden honey — hexagonal
wax cells filled with glowing amber honey, a thick glossy drip falling from
the top with a fat droplet at its end, warm directional light, shallow depth
of field, and a gentle vignette — and writes it deterministically to
`/output/entry.png` (1024×1024 PNG, under 1 MiB).

Run it:

```sh
python3 main.py
```
